
# Tab Grouper

A tiny Firefox extension that groups tabs from the same website next to each other.

## Features
- One click (or **Alt+Shift+G**) to organize all open tabs by domain
- No data collected, no network requests

## Install
**From source (temporary):**
1. Clone this repo
2. Open `about:debugging#/runtime/this-firefox`
3. Click **Load Temporary Add-on** and select `manifest.json`

## Usage
Click the toolbar icon or press Alt+Shift+G.

## Permissions
- `tabs`: read tab URLs and reorder them
- `storage`: save your settings
